# DSLQ: Log-Determinant Estimation

Research code for **DSLQ**, a randomized range-projected stochastic Lanczos quadrature estimator for the log-determinant of a large symmetric positive-definite matrix, together with the synthetic experiments used to study its randomized range construction and residual bound.

## Main estimator

The public estimator is:

```python
from src.dslq import dslq_logdet
```

The implementation uses the manuscript structure:

1. draw a randomized range sketch;
2. form `Y = (J - gamma I) S`;
3. compute an orthonormal basis of the range;
4. estimate the projected log-trace contribution by SLQ;
5. estimate the complementary residual with projected Rademacher probes;
6. add the scaling correction when `J = Q / alpha` is used.

## Reproduce the ecology2 experiment

Put `ecology2.mat` in `data/`, then run:

```bash
python experiments/ecology2_dslq.py
```

The supplied configuration uses `mvec=30`, `s=r=10`, projected degree `m=89`, and residual degree `m'=90`, giving exactly

```text
10 + 10*89 + 10*90 = 1800
```

log-determinant matrix-vector products.

## Validate the Theorem 2.2 residual bound

```bash
python experiments/theorem_2_2_validation.py
```

This performs 400 independent Monte Carlo realizations on six synthetic spectra and compares the empirical mean of

```text
||(I-P) log(J)||_F^2
```

against the theoretical upper bound. Figures and the numerical table are saved under `results/`.

## Randomized range comparison

```bash
python experiments/randomized_range_comparison.py
```

This compares ranges generated by `JS`, `(J-I)S`, and `log(J)S`, including their corresponding bounds and the optimal rank-k spectral tail.
